# Backend Development Workflow

1. Read task state.
2. Read feature spec.
3. Read relevant architecture and ADRs.
4. Read `docs/standards/BACKEND.md`.
5. Read approved contracts.
6. Implement only approved scope.
7. Keep transport, business logic, and persistence concerns separated.
8. Add/update tests.
9. Run backend verification.
10. Write `backend-report.json`.
11. Do not silently change frontend or API contracts.
