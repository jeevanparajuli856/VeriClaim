# Feature Planning Workflow

1. Read `AGENTS.md`.
2. Read the task file.
3. Read system architecture and relevant ADRs.
4. Define the feature goal.
5. Define in-scope and out-of-scope behavior.
6. Identify backend, frontend, database, security, and infrastructure impact.
7. Identify required contract changes.
8. Define acceptance criteria.
9. Record risks and dependencies.
10. Update `docs/features/<TASK-ID>.md`.
11. Do not implement production code during planning unless explicitly requested.
