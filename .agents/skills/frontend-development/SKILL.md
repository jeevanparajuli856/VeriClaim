# Frontend Development Workflow

1. Read `AGENTS.md` and `GEMINI.md`.
2. Read task state.
3. Read feature spec.
4. Read `docs/standards/FRONTEND.md`.
5. Read `contracts/openapi.yaml`.
6. Never invent API endpoints.
7. Implement loading, error, empty, and success states.
8. Preserve accessibility.
9. Add/update frontend tests.
10. Run lint, typecheck, tests, and build.
11. Write `frontend-report.json`.
12. Report contract blockers instead of editing backend/contract scope.
